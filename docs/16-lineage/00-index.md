# 16 — Lineage entries

One file per source. Each carries the same five sections: what it is, the mechanisms worth taking,
candidates tagged to Question Book IDs, an ambiguity section resolving where the source's own canon
is contested or thin, and what **not** to take.

Every candidate below is a proposal. None of them is an answer until it has been spoken with a
stake marker, per [15 — The Question Book](../15-the-question-book.md).

**List** records which co-founder named the source. That column is the point of the ledger — where
both lists name the same source, or the same ID, the disagreement is worth more than either answer.

## Cheapest strong candidates

Nothing in the engine, most fiction changed:

- `LF1`/`OT4` (16.14) — gate-things are **incomplete**; the named ones stop being monsters
- `MK12` (16.10) — every charm names a dead maker
- `LN6`/`MX8` (16.15) — each site holds you for its own number of steps
- `SM8` (16.5) — the name surfaces later, somewhere you went for another reason
- `FA8` (16.9) — the Training Yoke has a lineage and a dead master
- `AR2` (16.13) — one settlement is warded instead of walled, because of what flies
- `DY1` (16.7) — every villager knows one thing and has one thing
