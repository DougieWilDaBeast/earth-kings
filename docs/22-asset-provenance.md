# 22 — Asset provenance

Where every file under `art/`, `audio/` and the fonts came from, and whether the game can ship with
it. First audit 2026-10-12, from what the repository itself records: `metadata.json` files, file
tags, project files, and the docs. Nothing was taken on trust that is not written down somewhere,
and no asset was moved, changed or deleted.

The player-facing version is the Credits screen (title → **Credits**, or `Esc` → **Credits** in
game), read from [`data/credits.json`](../data/credits.json) ([04](04-data-formats.md#creditsjson--the-credits)).
When a row here changes status, change the credits to match.

## Status

| Status | Meaning |
| --- | --- |
| **cleared** | Source known, licence allows shipping. Nothing to do |
| **not shipped** | Kept in the repository but left out of every build (`.gdignore`, or the export `exclude_filter`). Must stay that way |
| **to confirm** | Source not recorded, or recorded but its terms not checked. A founder fills in the gap |
| **dev only** | Known third-party material in the game for development. **Must be replaced or licensed before any public release** |
