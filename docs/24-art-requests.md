# 24 — Art requests

**The art waiting to be made, one request per row.** This is the short, current to-do list;
[19 — Asset list](19-asset-list.md) is the long plan it is taken from.

## How it works

1. **Asking.** When the game needs art, the request is written here: what it is, how big, how it
   should look, and where it goes. `doug-md` (or a coding agent working with him) adds it.
2. **Telling.** `doug-md` tells `dougie` there is art to make. Only `dougie`'s PixelLab account
   generates art.
3. **Making.** `dougie` makes each open request, with `tools/pixellab.py` or the PixelLab website,
   and puts the results in `DROP-ZONE/<request id>/` (for example `DROP-ZONE/A1/`). The PixelLab
   export zip is fine as it is.
4. **Closing.** Whoever wires the art into the game moves it from `DROP-ZONE/` into `art/`, keeps
   its `metadata.json`, and moves the row to **Done** with the date.

**While PixelLab has no credits** ([D111](06-decisions.md), 2026-10-15), the art the First Hour needs is
drawn in house by the `tools/draw_*.py` scripts at the art's own size, and listed in
[22](22-asset-provenance.md). A request stays open here until PixelLab art of the same name replaces
the in-house stand-in; the keepsakes A10 to A25 are the coin pile until then. PixelLab's credits come back on
**27 October 2026** (22 euro a month, paid by `dougie`, [D213](06-decisions.md)); the order then is [D199](06-decisions.md)'s, A9 first.

Every request follows the [conventions in 19](19-asset-list.md#conventions): dark fantasy, muted
colours ([D40](06-decisions.md)), the 64 class on the founders' base body ([D55](06-decisions.md)),
big units drawn bigger.

## Taking art in

Where every open request from A51 lands, the size of each file and what in the game shows it are in
`data/art_slots.json` ([D344](06-decisions.md)); the game already reads each of those places (all but A54's
fall strip, which waits for its cinematic), and shows nothing new (or the in-house stand-in) until a picture is there. So on a day with credits the job is only
to generate: make a request's files at the sizes the slot gives, drop them (loose PNGs or PixelLab's zip)
in `DROP-ZONE/<id>/`, then

    python3 tools/take_art.py check          what is dropped, what is in place, what is still to make
    python3 tools/take_art.py take A53       check each file's size and move it where the game reads it

A file the wrong size is not moved and is said. After a take, import in Godot and move the row to Done.
